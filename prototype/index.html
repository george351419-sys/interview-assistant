使用说明
  1. 先在上方填入目标 JD 和简历并保存。
  2. 回到主界面，点快捷题 / 输入问题 / 对着麦克风说。
  3. 手机提示屏约 1–3 秒出结构化提示；自己说话时点「我在说话」体验自动收起。
  4. 每轮结束在提示卡或回溯里标注「答得好 / 卡壳」，用于复盘。

真实 M0 还需 macOS 虚拟声卡（BlackHole）+ 声纹模型 + WebSocket + iOS 端；本原型用浏览器能力做了等价演示替代。
